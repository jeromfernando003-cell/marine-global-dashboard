# Marine Global Dashboard

This repository contains a starter Next.js app (TypeScript) and a World Clock component that displays current time in multiple IANA time zones.

What I added now
- Full Next.js scaffold (package.json, tsconfig, pages, global styles)
- World Clock component and /clock page (already added)

Run locally (simple steps)
1. Clone the repo:
   git clone https://github.com/jeromfernando003-cell/marine-global-dashboard.git
2. Install dependencies:
   cd marine-global-dashboard
   npm install
3. Start dev server:
   npm run dev
4. Open in browser:
   http://localhost:3000/clock
